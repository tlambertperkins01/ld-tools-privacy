# Credible third-party review sources

A product enters the candidate pool only if at least one **credible tester**
recommends it. "Credible" = independent editorial team, hands-on testing, a
stated methodology, and corrections/updates over time.

## General (most categories)

| Outlet | Notes |
|---|---|
| Wirecutter (NYT) | Strongest single source; lists top / budget / upgrade / "also great" picks and **explains former picks it dropped**. Often blocks fetchers: use a browser or search snippets. |
| Consumer Reports | Lab testing; often paywalled. Snippets still give ratings. |
| America's Test Kitchen / Cook's Illustrated / Cook's Country | Kitchen gold standard. Ratings: Winner, Best Buy, Highly Recommended, Recommended, Recommended with Reservations, Not Recommended. Treat "with Reservations" as marginal. |
| Serious Eats | Kitchen; methodical testing. |
| CNN Underscored, NBC Select, USA Today Reviewed | Tested roundups; Reviewed has lab testing. |
| Good Housekeeping Institute | Lab-tested, all categories. |
| The Spruce Eats / Food & Wine / Food Network / Epicurious / Bon Appétit | Kitchen; check that the article says it was tested. |
| Forbes Vetted | Usable if the article states hands-on testing. |
| RTINGS | TVs, monitors, headphones, mice, keyboards, vacuums, mattresses. Measurement-based. |
| Tom's Guide / TechRadar / The Verge / Ars Technica / PCMag | Electronics and software. |
| Outdoor Gear Lab / Switchback Travel | Outdoor gear. |
| Sleep Foundation / Sleepopolis (check affiliate bias) | Mattresses. |
| Car and Driver / Edmunds | Vehicles and accessories. |
| Reddit category subs (r/BuyItForLife, r/Cooking, r/headphones…) | **Corroboration only**, never the entry ticket. Valuable for long-term durability complaints. |

## Red flags (reject as an entry source)

- The brand's own blog or "comparison" table (e.g. a brand ranking itself #1).
- Sites with no named authors, no methodology, and a "best X" page for
  everything (thewearify, thirstybear-type, *.pages.dev, *.blogspot,
  *.wasmer.app mirrors).
- AI-generated listicles that cite only Amazon star ratings.
- "Tested" claims with no photos, measurements, or comparisons.
- Pages that copy a credible outlet's text (mirrors): find the original.

## What to record

`Outlet · award/rank · date of review (or "undated") · short quote · URL ·
main criticism`. A review older than ~2 years: still count it, but note the
date and check whether the product line changed since.

## Weighting

- 2+ credible outlets agree → strong.
- 1 credible outlet → acceptable; say "single-source."
- Credible outlet **warns against** it, or dropped it after long-term testing → drop it,
  or keep it only as an explicit "fallback with known flaw."
